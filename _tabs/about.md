I'm **Ahmed Gamal** - Snow to the internet - an AI engineer building citation-grounded RAG and agent systems.
The rule everything here is built around: cited answers or safe refusal, never a confident guess.

## What I build

**Retrieval that can be audited.**
Hybrid dense-plus-sparse retrieval fused with reciprocal rank fusion, a deterministic guardrail that runs before any model is called, and fail-closed citation gates that refuse when the retrieved context does not support the answer.

**Agents with typed edges.**
LangGraph supervisor and single-graph designs with Pydantic output contracts, secured file and API tools, and human-in-the-loop approval instead of open-ended loops.

**Evaluation as part of the deliverable.**
Versioned golden sets, Ragas and Harbor suites, LLM-as-judge gates where deterministic checks cannot answer the question, and the misses published next to the wins.

Day to day: Python 3.12, LangGraph and LangChain, Qdrant, Pydantic v2, FastAPI, Streamlit and Docker, with models on AWS Bedrock, OpenAI, Groq and Gemini, and tracing through LangSmith.
