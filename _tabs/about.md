## What I build

**Harnesses, not prompts.**
Most of the work is the loop around the model: planning, tool calls, state, retries, and the context the model actually gets to see.
I write the design down before I write the code, because the harness is where reliability is won or lost.

**Evidence-first retrieval.**
Hybrid dense-plus-sparse retrieval fused with reciprocal rank fusion, deterministic guardrails before any model call, and fail-closed citation gates.
The system cites the source or refuses.
It does not guess.

**Deterministic cores, typed edges.**
LangGraph graphs with Pydantic contracts and secured tools, while plain Python owns routing, money math, and side effects.
A model reads messy input and writes prose; tested code decides what happens next, and risky cases wait for a human.

**Evaluation as part of the deliverable.**
Versioned golden sets, Ragas suites, and LLM-as-judge gates where deterministic checks cannot answer the question.
The misses get published next to the wins.

Day to day: Python 3.12 and 3.13, LangGraph, Deep Agents and Pydantic AI, FastAPI, Postgres, Qdrant, React, Docker, and Docling, with models on AWS Bedrock, OpenAI, Groq, Cerebras and NVIDIA, and tracing through LangSmith.
